# Twelve Full PNG Organized

This folder is a best-effort reorganization of `reference/twelvefull_png`.

Important notes:
- `character_npc/*` is the closest reliable split from the decompiled client.
- Offline IDs `798xx`, `799xx`, `899xx`, `990xx` were grouped from character appearance logic.
- No clearly separate built-in `npc` sprite atlas was found in the jar.
- NPC visuals likely reuse the same character body-part system or are downloaded/runtime-built.
- Files outside these known ranges stay in `offline_unclassified` or `uncategorized_named`.
