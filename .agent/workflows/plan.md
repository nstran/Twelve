# /plan - Strategic Planning

$ARGUMENTS

1. **Invoke**: `project-planner` agent (or self-plan).
2. **Identify**: Map affected layers (Core, Application, Infrastructure) and dependencies.
3. **Output**: Create an `implementation_plan.md` artifact with `request_feedback = true`.
4. **Format**: Must include Goals, Proposed Changes (grouped by layer), Open Questions, and Verification Plan.

**No-Code Zone**: Do not write any production code during this phase.
